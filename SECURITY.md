# Security reports

Do not post credentials, session cookies, password hashes or private team data in public issues. Use GitHub's private vulnerability reporting for this repository when enabled, or contact the maintainer through their published profile.

This is an early preview. It uses HttpOnly/SameSite cookies, scrypt password hashes, hashed session tokens, origin checks for browser writes, rate limits, role checks and optimistic task/page locking. These measures do not constitute an independent security audit. See the roadmap for operational and security work still required.
