# توصيل وكيل AI بـ TaskOrbit

[English](MCP.md) · [فارسی](MCP.fa.md) · [العربية](MCP.ar.md) · [简体中文](MCP.zh-CN.md)

يسمح MCP لوكيلك بقراءة وإدارة العمل على خادمك الخاص. لا يثبت TaskOrbit نموذجًا؛ الوكيل الذي تختاره يتلقى البيانات التي تطلبها أدواته.

## ١. إنشاء رمز

سجّل الدخول إلى خادمك، ثم افتح **الإعدادات ← تكامل الوكلاء · MCP**. أدخل اسمًا ومدة صلاحية من ١ إلى ٣٦٥ يومًا (٣٠ افتراضيًا). ابدأ بالقراءة فقط؛ فعّل التعديل إذا أردت إنشاء المهام وتحديثها. إدارة الخادم صلاحية منفصلة للمسؤول وتمنح الوصول إلى كامل الخادم. بدونها يُقيّد رمز المسؤول بعضوياته في مساحات العمل.

اضغط **إنشاء رمز** واحفظه فورًا في إعدادات الوكيل الخاصة. يظهر مرة واحدة فقط؛ يخزن الخادم بصمة SHA-256. الرمز المفقود لا يمكن استعادته: ألغِه وأنشئ غيره. لا تضعه في Git. دور المستخدم يظل نافذًا؛ المشاهد لا يمكنه الكتابة حتى برمز تعديل. تغيير/إعادة تعيين كلمة المرور وتعطيل الحساب يلغي الرموز؛ تسجيل الخروج العادي لا يلغيها. استخدم **إلغاء** لقطع وصول الوكيل.

## ٢. إعداد الاتصال

الاتصال البعيد Streamable HTTP يستخدم `https://tasks.example.com/mcp` ويتطلب عميلًا يدعم ترويسة Bearer. لا يحتاج Node.js. جسر stdio المحلي يتطلب Node.js ≥22.18 على جهاز الوكيل ويستخدم عنوان الخادم الجذري بدون `/mcp` أو `/api`. استبدل الدومين بخادمك. HTTP مسموح فقط لـ localhost للتطوير. لا توجد حاوية إضافية. يجب أن يطابق APP_ORIGIN عنوان HTTPS العام وأن يحافظ الوكيل العكسي على Host.

### Codex

عرّف المتغير الخاص TASKORBIT_TOKEN في بيئة تشغيل الوكيل. PowerShell: `$env:TASKORBIT_TOKEN = 'YOUR_TOKEN'`؛ macOS/Linux: `export TASKORBIT_TOKEN='YOUR_TOKEN'`. يستفيد منه التطبيق الذي تشغله من هذا الطرفية؛ لتطبيق سطح مكتب من القائمة استخدم إعدادات متغيرات المستخدم أو شغّله من الطرفية. أعد تشغيله بالكامل. أضف إلى `~/.codex/config.toml`:

```toml
[mcp_servers.taskorbit]
url = "https://tasks.example.com/mcp"
bearer_token_env_var = "TASKORBIT_TOKEN"
```

[المرجع الرسمي](https://developers.openai.com/codex/mcp/). تسجيل OAuth غير مطلوب.

### Cursor

أضف إلى ملفك الشخصي `~/.cursor/mcp.json` مع الحفاظ على الخوادم الموجودة، ثم أعد التشغيل بعد تعريف TASKORBIT_TOKEN:

```json
{
  "mcpServers": {
    "taskorbit": {
      "url": "https://tasks.example.com/mcp",
      "headers": { "Authorization": "Bearer ${env:TASKORBIT_TOKEN}" }
    }
  }
}
```

[مرجع Cursor](https://cursor.com/docs/mcp).

### Claude Code

ادمج في إعداد mcpServers الشخصي `~/.claude.json` أو `.mcp.json` باستخدام متغير البيئة، ثم أعد التشغيل وتحقق عبر `/mcp`:

```json
{
  "mcpServers": {
    "taskorbit": {
      "type": "http",
      "url": "https://tasks.example.com/mcp",
      "headers": { "Authorization": "Bearer ${TASKORBIT_TOKEN}" }
    }
  }
}
```

[المرجع الرسمي](https://code.claude.com/docs/en/mcp).

### Claude Desktop وstdio

ثبّت Node.js. افتح **Settings → Developer → Edit Config** وادمج JSON التالي. استبدل YOUR_TOKEN في الملف الخاص ولا تحفظه في مستودع:

```json
{
  "mcpServers": {
    "taskorbit": {
      "command": "npx",
      "args": [
        "-y",
        "--package=https://github.com/sajadjanat/taskorbit/releases/download/v0.2.1/taskorbit-mcp-0.2.1.tgz",
        "taskorbit-mcp"
      ],
      "env": {
        "TASKORBIT_SERVER": "https://tasks.example.com",
        "TASKORBIT_TOKEN": "YOUR_TOKEN"
      }
    }
  }
}
```

في **Windows** غيّر command إلى cmd وأضف `"/c", "npx"` في بداية args؛ دليل التطبيق يولّد النسختين. يجب أن تكون node/npm/npx على PATH؛ أعد تشغيل العميل بعد تثبيت Node. إذا تجاوز أول تنزيل مهلة البدء، استخدم `npm install -g <رابط الحزمة أعلاه>` ثم مسار الملف التنفيذي الكامل كـ command بلا args.

يمكن استخدام TASKORBIT_TOKEN_FILE بدل TASKORBIT_TOKEN: مسار مطلق لملف UTF-8 خاص يحتوي الرمز وحده، مقيد لمستخدم جهازك. يقرأه الجسر عند بدء التشغيل ويتقدم على متغير الرمز. الحزمة المنشورة موجودة في [GitHub Releases](https://github.com/sajadjanat/taskorbit/releases) مع SHA256SUMS؛ لا تتضمن بيانات أو كلمات مرور.

## ٣. التحقق والاستخدام

اطلب: **«استخدم TaskOrbit لعرض مساحات عملي.»** اختر مساحة ومشروعًا قبل التعديل. اطلب تأكيدًا قبل الحذف أو ترقية الخادم. يتضمن كتالوج المسؤول ٤٨ أداة لإدارة مساحات العمل والمشاريع والأعضاء والمهام والمهام الفرعية والأولويات والتقديرات والسبرنتات والوحدات والصفحات والعروض والتعليقات والنشاط والملفات والعلاقات والمستخدمين والتصدير والتحديثات. الرموز الأقل صلاحية ترى أدوات أقل. لا يتوفر حاليًا حذف السبرنت أو تعديل/حذف التعليقات؛ إكمال السبرنت متاح.

تعديل المهمة/الصفحة يتطلب النسخة المقروءة؛ 409 يمنع الكتابة فوق تعديل أحدث. القوائم تدعم limit من ١ إلى ٢٠٠ وoffset. الملفات حتى ١٠ MiB و٢٠ ملفًا للمهمة؛ تنزيل المحتوى محدود افتراضيًا بـ٦٤ KiB. تغييرات الوكيل تظهر مباشرة على الويب والعملاء.

| المشكلة              | الحل                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| 401                  | تحقق من الرمز وانتهائه وإلغائه والدومين؛ كوكي الدخول ليس رمز MCP.            |
| 403                  | تحقق من صلاحية الرمز ودور المستخدم في مساحة العمل.                           |
| أدوات التعديل مفقودة | أنشئ رمزًا يسمح بالتعديل وأعد تشغيل الوكيل.                                  |
| 409                  | اقرأ النسخة الحالية ووفّق التغييرات قبل الحفظ.                               |
| 429                  | انتظر قبل إعادة المحاولة.                                                    |
| تعذر الاتصال         | تحقق من HTTPS والشهادة وAPP_ORIGIN؛ الجسر يستخدم الجذر والاتصال البعيد /mcp. |
| 405 في المتصفح       | طبيعي؛ /mcp يستقبل POST للبروتوكول وليس صفحة ويب.                            |
| npx غير موجود        | ثبّت Node.js وتحقق من PATH ومثال Windows.                                    |
| العميل يتطلب OAuth   | استخدم stdio أو عميلًا يدعم Bearer؛ OAuth غير متاح في هذه النسخة.            |

يدعم الإصدار stdio وStreamable HTTP بلا جلسة مع JSON؛ لا يدعم HTTP+SSE القديم أو OAuth أو إشعارات MCP من الخادم. اختُبرت البروتوكولات باستخدام SDK الرسمي؛ لم يُتحقق من تثبيت كل تطبيق طرف ثالث على جهاز فعلي. [التفاصيل الإنجليزية](MCP.md).
