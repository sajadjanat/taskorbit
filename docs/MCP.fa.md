# اتصال ایجنت به TaskOrbit با MCP

[English](MCP.md) · [فارسی](MCP.fa.md) · [العربية](MCP.ar.md) · [简体中文](MCP.zh-CN.md)

MCP به ایجنت اجازه می‌دهد اطلاعات کاری را از سرور شخصی شما بخواند و مدیریت کند. خود TaskOrbit مدل هوش مصنوعی نصب نمی‌کند؛ ایجنت انتخابی شما اطلاعاتی را دریافت می‌کند که ابزارهایش درخواست می‌کنند.

## ۱. توکن بسازید

1. در وب یا کلاینت متصل به سرور خود وارد شوید و **تنظیمات ← اتصال ایجنت‌ها · MCP** را باز کنید.
2. نامی مثل «ایجنت من» و اعتبار ۱ تا ۳۶۵ روز تعیین کنید؛ پیش‌فرض ۳۰ روز است.
3. برای شروع مجوز خواندن کافی است. اگر ایجنت باید تسک بسازد یا ویرایش کند، **اجازهٔ ویرایش اطلاعات کاری** را فعال کنید. مدیریت کل سرور مجوز جداگانه‌ای است و فقط ادمین می‌تواند آن را بدهد؛ دسترسی سراسر سرور را تنها به ایجنت مورد اعتماد بدهید. توکن ادمین بدون این مجوز به عضویت‌های همان ادمین در فضاهای کاری محدود می‌شود.
4. **ساخت توکن** را بزنید و آن را همان لحظه ذخیره کنید. فقط یک بار نمایش داده می‌شود؛ سرور فقط هش SHA-256 را نگه می‌دارد. اگر گم شد، لغو کنید و توکن تازه بسازید.

نقش کاربر همچنان اعمال می‌شود؛ کاربر مشاهده‌گر با توکن نوشتن هم نمی‌تواند ویرایش کند. تغییر عضویت بلافاصله در عملیات بعدی اعمال می‌شود. تغییر یا ریست رمز و غیرفعال‌شدن حساب، توکن‌ها را لغو می‌کند. خروج معمولی از اپ توکن ایجنت را لغو نمی‌کند؛ برای قطع اتصال **لغو** را بزنید. ساخت و لغو توکن فقط از اپ واردشده ممکن است.

## ۲. روش اتصال را انتخاب کنید

اتصال راه دور **Streamable HTTP** به Node.js نیاز ندارد و برای ایجنت دارای قابلیت ارسال هدر Bearer مناسب است. نشانی آن `https://tasks.example.com/mcp` است. پل محلی **stdio** برای Claude Desktop و ایجنت‌های دارای اجرای برنامهٔ محلی مناسب است و به Node.js نسخهٔ 22.18 یا بالاتر نیاز دارد؛ اولین نصب بسته به اینترنت نیاز دارد. هر دو روش به همان سرور موجود وصل می‌شوند و کانتینر اضافه لازم نیست.

`tasks.example.com` را با دامنهٔ سرور خود جایگزین کنید. پل محلی باید نشانی ریشه، بدون `/mcp` یا `/api`، بگیرد. اتصال HTTP بدون TLS فقط برای localhost توسعه پذیرفته می‌شود. مدیر سرور باید `APP_ORIGIN` را روی نشانی عمومی HTTPS بگذارد و هدر Host در پراکسی حفظ شود.

### Codex

توکن را در متغیر خصوصی `TASKORBIT_TOKEN` در محیط اجرای Codex تعریف کنید. PowerShell: `$env:TASKORBIT_TOKEN = 'YOUR_TOKEN'`؛ مک/لینوکس: `export TASKORBIT_TOKEN='YOUR_TOKEN'`. جای‌نگهدار را خصوصی جایگزین کنید. این روش فقط همان ترمینال و برنامه‌های اجراشده از آن را پوشش می‌دهد؛ برای اجرای دسکتاپ از منو، متغیر محیطی کاربر سیستم‌عامل را تنظیم کنید یا اپ را از همان ترمینال باز کنید. توکن را در اسکریپت مشترک یا گیت نگذارید. بعد اپ را کامل ببندید و دوباره باز کنید.

در فایل خصوصی `~/.codex/config.toml` اضافه کنید:

```toml
[mcp_servers.taskorbit]
url = "https://tasks.example.com/mcp"
bearer_token_env_var = "TASKORBIT_TOKEN"
```

یا از ترمینال تنظیم‌شده اجرا کنید:

```sh
codex mcp add taskorbit --url https://tasks.example.com/mcp --bearer-token-env-var TASKORBIT_TOKEN
```

ورود OAuth لازم نیست؛ این اتصال از توکن شخصی استفاده می‌کند. [مرجع رسمی](https://developers.openai.com/codex/mcp/).

### Cursor

متغیر `TASKORBIT_TOKEN` باید در محیط اجرای Cursor موجود باشد. این بخش را با تنظیمات موجود `~/.cursor/mcp.json` ادغام و اپ را دوباره اجرا کنید:

```json
{
  "mcpServers": {
    "taskorbit": {
      "url": "https://tasks.example.com/mcp",
      "headers": { "Authorization": "Bearer ${env:TASKORBIT_TOKEN}" }
    }
  }
}
```

[راهنمای رسمی Cursor](https://cursor.com/docs/mcp).

### Claude Code

متغیر محیطی را تعریف کنید؛ این بخش را با تنظیمات شخصی `~/.claude.json` یا فایل `.mcp.json` بدون درج رمز واقعی ادغام کنید. بعد اپ را دوباره اجرا و `/mcp` را بررسی کنید:

```json
{
  "mcpServers": {
    "taskorbit": {
      "type": "http",
      "url": "https://tasks.example.com/mcp",
      "headers": { "Authorization": "Bearer ${TASKORBIT_TOKEN}" }
    }
  }
}
```

[راهنمای رسمی Claude Code](https://code.claude.com/docs/en/mcp).

### Claude Desktop و ایجنت‌های stdio

Node.js را نصب کنید. در Claude Desktop از **Settings → Developer → Edit Config** فایل MCP را باز کنید. تنظیمات زیر را با سرورهای موجود ادغام کنید؛ YOUR_TOKEN را در فایل خصوصی جایگزین کنید و فایل را در گیت نگذارید:

```json
{
  "mcpServers": {
    "taskorbit": {
      "command": "npx",
      "args": [
        "-y",
        "--package=https://github.com/sajadjanat/taskorbit/releases/download/v0.2.1/taskorbit-mcp-0.2.1.tgz",
        "taskorbit-mcp"
      ],
      "env": {
        "TASKORBIT_SERVER": "https://tasks.example.com",
        "TASKORBIT_TOKEN": "YOUR_TOKEN"
      }
    }
  }
}
```

**ویندوز:** command را `cmd` کنید و `"/c", "npx"` را ابتدای args بگذارید. راهنمای داخل اپ هر دو نمونهٔ ویندوز و مک/لینوکس را آماده می‌کند. Node و npx باید در PATH ایجنت باشند؛ بعد از نصب Node ایجنت را کامل ببندید و باز کنید. اگر اولین دانلود از مهلت شروع ایجنت بیشتر شد، با `npm install -g <نشانی بستهٔ بالا>` از قبل نصب کنید و مسیر کامل برنامهٔ نصب‌شده را بدون args در command بگذارید.

به‌جای ذخیرهٔ توکن در JSON می‌توانید `TASKORBIT_TOKEN_FILE` را روی مسیر مطلق فایل UTF-8 خصوصی شامل فقط توکن بگذارید. دسترسی فایل را به کاربر خود محدود کنید؛ این متغیر بر TASKORBIT_TOKEN اولویت دارد و فقط در شروع خوانده می‌شود. بستهٔ نسخه‌دار در [ریلیز گیت‌هاب](https://github.com/sajadjanat/taskorbit/releases) و هش آن در SHA256SUMS قرار می‌گیرد. بسته فقط پل ارتباطی است و دیتابیس یا رمز آماده ندارد.

## ۳. اتصال را آزمایش کنید

به ایجنت بگویید: **«با TaskOrbit فضاهای کاری من را فهرست کن.»** باید list_workspaces اجرا شود. سپس فضای کاری و پروژه را انتخاب کنید. برای ویرایش، توکن با مجوز ویرایش لازم است؛ پیش از حذف اطلاعات یا ارتقای سرور از ایجنت تأیید بخواهید.

مجموعهٔ کامل ادمین ۴۸ ابزار دارد: پروژه‌ها و فضاهای کاری، اعضا، تسک و زیرتسک، اولویت و برچسب و تخمین، اسپرینت، ماژول، صفحه و نمای ذخیره‌شده، کامنت، تاریخچه، فایل‌ها و وابستگی‌ها، کاربران، خروجی اطلاعات و به‌روزرسانی سرور. توکن عادی ابزارهای کمتری می‌بیند. پرامپت getting_started نیز موجود است. ابزارها امکانات واقعی API را ارائه می‌کنند: پایان‌دادن اسپرینت موجود است؛ حذف اسپرینت و ویرایش/حذف کامنت هنوز پیاده نشده‌اند.

ویرایش تسک/صفحه نسخهٔ خوانده‌شده را می‌خواهد؛ نسخهٔ قدیمی 409 می‌گیرد. فهرست‌ها limit برابر ۱ تا ۲۰۰ و offset دارند. هر فایل حداکثر ۱۰ MiB و هر تسک حداکثر ۲۰ فایل دارد؛ دانلود فایل پیش‌فرض به ۶۴ KiB محدود است. تغییرات ایجنت هم در وب و کلاینت‌ها زنده نمایش داده می‌شوند.

| خطا                      | راه‌حل                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| 401                      | توکن، انقضا و دامنه را بررسی کنید؛ کوکی ورود توکن MCP نیست. در صورت نیاز توکن تازه بسازید. |
| 403                      | مجوز توکن و نقش کاربر در فضای کاری را بررسی کنید.                                          |
| ابزار ویرایش نیست        | توکن با اجازهٔ ویرایش بسازید و ایجنت را دوباره اجرا کنید.                                  |
| 409                      | آخرین اطلاعات را بخوانید، تغییرات را تطبیق دهید و با نسخهٔ جدید ذخیره کنید.                |
| 429                      | کمی صبر کنید؛ درخواست‌ها را پشت سر هم تکرار نکنید.                                         |
| خطای شبکه                | HTTPS، گواهی، دامنه و APP_ORIGIN را بررسی کنید؛ پل نشانی ریشه می‌گیرد و HTTP راه دور /mcp. |
| 405 در مرورگر            | طبیعی است؛ /mcp صفحهٔ وب نیست و POST پروتکل می‌گیرد. از ایجنت MCP استفاده کنید.            |
| npx پیدا نمی‌شود         | Node.js و PATH را بررسی کنید؛ در ویندوز از نمونهٔ cmd استفاده کنید.                        |
| ایجنت فقط OAuth می‌خواهد | این نسخه توکن Bearer دارد؛ روش stdio یا کلاینت دارای هدر اختصاصی را استفاده کنید.          |

این نسخه stdio و Streamable HTTP بدون نشست را با پاسخ JSON ارائه می‌کند؛ OAuth و HTTP+SSE قدیمی ندارد. اتصال هر دو روش با SDK رسمی تست شده است؛ نصب و رابط هر محصول ثالث جداگانه روی دستگاه واقعی تأیید نشده. [جزئیات انگلیسی](MCP.md) و [مرجع پروتکل](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports).
