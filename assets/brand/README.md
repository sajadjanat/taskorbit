# TaskOrbit brand

Current transparent wordmarks: `taskorbit-wordmark-v5-light.png` (charcoal letters) and `taskorbit-wordmark-v5-dark.png` (ivory letters), with sunlit Mercury as the O and a small k/r overlap. Current square app icon: `taskorbit-icon.png`. Stone/charcoal surfaces and solar-gold accents match this identity. See [prompts and versions](WORDMARK.md).

The application uses `public/wordmark-light.png` and `public/wordmark-dark.png`, following its selected theme. `public/wordmark.png` is a compatibility copy of the dark-theme version. README uses a `picture` element for GitHub light/dark preferences. Historical artwork is preserved. Lettering was matched to the owner's GitOrbit reference using built-in imagegen; no separate font file has been identified.

Run `npm run icons` to regenerate native and PWA icons, including the charcoal Android adaptive-icon background and the maskable safe zone.
